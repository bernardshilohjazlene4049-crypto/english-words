专项一 · 讲义 P1–P3

时态和语态（Tense & Voice）

锁定时间特征与时点/时段差异，吃透主将从现、完成时四大标志、瞬间动词转化与主动表被动。

一、时态概念与可视化时间轴

时态 = 动作发生的时间（过去 / 现在 / 将来 / 过去将来）+ 动作所处的状态（一般 / 进行 / 完成 / 完成进行）。

1. 时态判断三步法：通过 时间 特征锁定具体时态： 1）找明显时间状语/标志词（如 yesterday / since / by 2030）　 2）看上下文其他动词时态（保持语境一致）　 3）按常识、客观真理或固定句型判断（如主将从现、It is the first time...）
时间特征与高频标志词对应时态动词形式（主动）
经常/习惯/反复发生、客观真理（every day, always, often, usually, seldom）一般现在时do / does（am/is/are）
过去某一具体时间点（yesterday, ...ago, last..., in 2020, just now）一般过去时did（was/were）
将来发生的动作（tomorrow, next..., in + 一段时间, soon, in the future）一般将来时will / shall do；be going to do
此时此刻 / 现阶段正在进行（now, at the moment, look, listen, these days）现在进行时am / is / are doing
过去某时间点正在进行（at this time yesterday, at 8 last night, when+过去）过去进行时was / were doing
过去持续到现在 / 影响至今（since+过去点, for+时段, so far, up to now, in the past+时段, already, yet）现在完成时have / has done
过去的过去（by+过去时间, by the time+一般过去, before+过去动作）过去完成时had done
到将来某时刻之前已完成（by+将来时间, by the time+一般现在表将来）将来完成时will have done
过去开始一直持续到现在且仍在进行（强调动作持续不断）现在完成进行时have / has been doing
立足过去看将来（主句过去时的宾语从句中）过去将来时would do / was(were) going to do
时点 vs 时段
时点：具体某一时刻（yesterday / in 2020 / at 5 p.m.）→ 一般/进行时
时段：持续一段时间（for 3 years / since 2020 / in the past 5 years）→ 完成时
三组必区分易混时态
注意区分 一般过去时 和 现在完成时、一般过去时 和 过去完成时、现在完成时 和 过去完成时

核心考点 1 & 2：反复发生 & 主将从现 & “一…就…”

  • 考点 1（反复发生 / 客观真理）：不管前后什么时态，只要满足反复发生或客观事实（如太阳东升西落、光速快于声速），就用 一般现在时。
  • 考点 2（主将从现）：
    （1）条件从句 if / unless 引导：从句：一般现在时（do / does），主句：一般将来时（will do / 祈使句 / 情态动词+do）。
    （2）时间从句：when, after, before, as soon as 表示动作一 先 一 后（主句将来，从句用一般现在表将来）。
🔥 重点：“一…就…” 3 个核心短语与 2 大高频考点：
  1. as soon as（引导时间状语从句，表将来时遵循主将从现；表过去时主从句均用一般过去时）
  2. no sooner ... than ... — 前 had done（过去完成时） 后 did（一般过去时）
  3. hardly / scarcely ... when ... — 前 had done（过去完成时） 后 did（一般过去时）
总结两考点：（1）固定搭配：前 no sooner — 后 than；前 hardly / scarcely — 后 when。
（2）时态与倒装：前 过去完成时 had done（放句首须部分倒装：No sooner / Hardly had + 主语 + done） — 后 一般过去时 did。

核心考点 3：完成时全攻略与非延续性动词转化

1. when + 过去（两个发生在过去的动作）

（1）两个动作 同时 发生（一长一短）：从句 一般过去时 did，主句 过去进行时 was/were doing。

（2）两个动作 先后 发生（主句先完成）：从句 一般过去时 did，主句 过去完成时 had done。

4. 将来完成时（will have done）

（1）by + 将来时间点（如 by 2030 / by next month / by the end of this year）

（2）by the time + 一般现在时从句（从句表将来，主句用 will have done）

2. 现在完成时 4 大高频标志（have/has done）
  1. since + 过去时间点/一般过去时从句；for + 时间段
  2. so far / up to now / by now / already / yet / recently
  3. in / during / over the past (last) + 数字 + years
  4. It / This is the first/second... time (that) + have/has done（含最高级修饰）
3. 过去完成时 4 大高频标志（had done）
  1. by + 过去时间点 / by the end of + 过去时间
  2. by the time / before / when + 一般过去时（强调主句动作先完成）
  3. It / This was the first/second... time (that) + had done
  4. no sooner...than / hardly(scarcely)...when（前 had done 后 did）
⚠️ 易错注意（瞬间动词转化）：完成时表示时间（段），因此与 for / since / how long 连用时，不能 + 瞬间（非延续性） 动词，只能 + 延续性 状态：
begin / start → be on leave → be away (from) sit → be seated die → be dead buy → have borrow → keep join → be in / be a member of marry → be married

二、语态（被动语态、无被动动词、主动表被动、by 四大用法）

被动语态公式：be + done（过去分词），各时态只需改变助动词 be 的形式。

1. 部分动词 词性（不及物） 上没有被动（用中文加“被”翻译不通 / 无宾语 即可检验）
  • （1）发生：happen / occur / take place / come about
  • （2）开始：begin / start（作不及物“开始”时，如 The class begins at 8.）
  • （3）属于：belong to
  • （4）爆发：break out
  • （5）起飞：take off（另：appear / disappear / consist of / remain 均无被动）
2. 主动表被动（通常用 一般现在 时态）
  • （1）表示主语 性质、特征 / 属性 — 五个词「写洗切卖燃烧」：
    write（写）、wash（洗）、cut（切）、sell（卖）、burn（燃烧）
    例：The book sells well. / The pen writes smoothly. / This cloth washes easily.
  • （2）感官系动词：look（看起来）、sound（听起来）、smell（闻起来）、taste（尝起来）、feel（摸起来） + 形容词
    例：The soup tastes delicious. / The silk feels soft.
🎯 by 四大高频考点用法（看到 by 先看后面跟什么）：
（1）by + 过去时间 → 过去完成时 had done （2）by + 将来时间 → 将来完成时 will have done （3）by + now → 现在完成时 have/has done （4）by + 人 / 方式 → 被动语态 be done by sb. / 通过…方式 by doing
专项二 · 讲义 P1–P4

虚拟语气（Subjunctive Mood）

抓住“时态往前退一步”底层逻辑，秒杀“厕所没水”互换、“贱命重要”省略倒装与含蓄虚拟。

核心考点 1：虚拟语气本质与 if 主从句虚拟表

表达含义：通过对真实情况进行 相反 假设，表达 愿望 / 遗憾、建议 / 后悔 之情。总规则：时态 往前退一步：现在 → 一般过去时；将来 → 过去将来 / should / were to；过去 → 过去完成时。

虚拟时间if 条件从句（真实 vs 虚拟）主句（真实 vs 虚拟）
对现在虚拟 真实：do / does
虚拟：did / were		 真实：do / will do
虚拟：would / could / should / might + do
对将来虚拟 真实：do / does（主将从现）
虚拟：did / were to do / should do		 真实：will do
虚拟：would / could / should / might + do
对过去虚拟 真实：did
虚拟：had done		 真实：did
虚拟：would / could / should / might + have done
💡 必背三大注释：
  1. “厕所没水”谐音口诀：could（厕）、should（所）、might（没）、would（水） — 在含 would 的主句虚拟结构中四者可互换！
  2. 虚拟语气中系动词的过去时一律只能用 were（不分人称，如 If I were you）。
  3. 主句用 would do 能不能直接判断虚拟时间？ 不能！ 因为对“现在”和对“将来”虚拟的主句都是 would do，必须通过时间标志词或从句形式判断（1.时间状语 2.另一半动词 3.上下文语境）。
虚拟语气 vs 主将从现（都是 if 引导从句）— 通过 动词形式 / 时态 区分：

（1）主将从现：从句 一般现在时，主句 一般将来时　｜　（2）虚拟语气：主、从句动词形式都是 过去相关形式（did / were / had done / would do）

讲义原题 1：If it rains tomorrow, we will close our restaurant. → A. 主将从现

讲义原题 2：If I were you, I would work much harder. → B. 虚拟语气（对现在虚拟）

核心考点 2、3、4：混合虚拟、if 省略倒装与 wish / would rather

考点 2：混合虚拟语气（错综时间条件句）

常规虚拟主从句时间 一致；混合虚拟主从句时间 不一致，主从句一般都有明显 时间状语 标志，各自按各自时间变化！

讲义原题 5：If I ____ hard 5 years ago, I would find a good job and live a perfect life now.
解析：从句 5 years ago（对过去虚拟）→ B. had studied；主句 now（对现在虚拟）用 would find。

考点 3：if 虚拟语气省略形式（倒装）

省略三步：（1）从句必须含有 were / had / should 三词之一；（2）省略 if；（3）将 were / had / should 提到主语前（否定词 not 留在主语后，绝不提前）。

还原两步：（1）见句首 Were / Had / Should + 主语，先在句首 补回 if；（2）将三词 放回主语之后 还原再做题。

引导词与含义对现在虚拟对过去虚拟对将来虚拟
wish（但愿/希望）
if only（要是…就好了）
as if / as though（好像/仿佛）		 did / were had done would / could / might + do
would rather / would sooner / had rather（宁愿） 现在 / 将来合并：did / were 过去：had done

核心考点 5：表“贱（建议）命（命令）重（重要）要（要求）”的虚拟语气

基本形式：（1）肯定：should + do，should 可省略 → 动词原形 do　｜　（2）否定：should not do → 省略后 not do　｜　（3）被动：should be done → 省略后 be done。
⚠️ 严禁互换：该考点下 should 与 would/could/might 不能 互换！只有初始规则用 would 时，“厕所没水”才可互换。
分类核心动词与同族词形派生（动 / 形 / 名全适用虚拟）
（1）建议advise → adj.advisable / n.advice；suggest → adj.suggestive / n.suggestion；propose → adj.proposed / n.proposal；recommend → n.recommendation
（2）要求、命令require → adj.required / n.requirement；request → adj.requested；demand → adj.demanding；order 两含义：（1）命令（虚拟）（2）订购/点餐/顺序（不虚拟） → adj.orderly；insist → adj.insistent
（3）重要、必要important、necessary（高频延伸：essential / vital / urgent / imperative / natural / strange）
suggest 两层含义（通过 主语与语境句意 判断）

1）表 “建议”（主语多为人）→ 虚拟语气 (should) + do

2）表 “表明 / 暗示”（主语常为物/迹象）→ 陈述语气（按真实时态）

insist 两层含义

1）坚持 要求 / 主张（应做某事）（前后人称 不一致）+ 虚拟语气 (should) + do

2）坚持 认为 / 强调（某事实）（前后人称 一致）+ 陈述语气（真实时态）

核心考点 6、7、8 与虚拟语气终极两大类总结

  • 考点 6：It is (about / high) time (that) + 虚拟：（1）did / were（一般过去时） 或 （2）should + do，其中 should 不能省略！
  • 考点 7：in case / lest / for fear that（以防 / 免得 / 唯恐）+ 虚拟：(should) + do（should 可省略）。
  • 考点 8：含蓄虚拟语气：从句没有 if，用 if 或 if not 的 介词短语 / 连词 / 副词 替换：
    • if 同义词：with / under...（如果有 / 在……条件下）
    • if not 同义词：but for / without...（要不是 / 如果没有）；or / otherwise（否则 / 要不然，一个词相当于 一个 if not 虚拟条件从句）
    • 变化规则：（1）不考虑 从句，只变化 主句；（2）对现在或将来虚拟：主句用 would/could/should/might + do；（3）对过去虚拟：主句用 would/could/should/might + have done。
第一类：含 would 主从句类虚拟（厕所没水可互换）

凡是规则中有 would 的考点，四词均可互换：① if 主从句　② if 省略倒装　③ 含蓄虚拟　④ wish / if only / as if（将来）。

第二类：should 类虚拟（should 能否省略口诀）

① “贱命重要” → should 可以 省略
② it is time that → should 不可 省略
③ in case / lest / for fear that → should 可以 省略

专项三 · 讲义 P1–P5

非谓语动词（Non-finite Verbs）

分清谓语与非谓语，牢记 3 步答题法、24 词动宾口诀、独立主格与 7 大高频杂项考点。

一、谓语 vs 非谓语核心概念与两张核心表

谓语动词五种形式：（1）do（动词原形） （2）does（三单） （3）did（过去式） （4）be / have / will + 动词（进行/完成/将来/被动） （5）情态动词 + do。
非谓语动词：（1）含义：在句中不能作谓语的动词变形 （2）成分：除谓语外的其他成分（主/宾/表/定/状/补）。
黄金铁律：一个句子在没有 连接词 的情况下，有且只有 1 个 谓语动词，其他动词都只能以 非谓语 形式出现。

考题秒认技巧：看选项，出现 to do、doing、done、having done 当中 2 个 选项以上考的就是非谓语！
答题三步法：① 选项找非谓语 → ② 判断作什么成分 → ③ 看主被动 +（时间词）。

二、作主语、作状语、作表语（成分判断精要）

1. 作主语（句首 + 谓语动词，无逗号）

（1）一般/习惯动作（动名词）：主动 doing / 被动 being done

（2）具体/一次性/将来（不定式）：主动 to do / 被动 to be done

2. 作状语（句首 + 逗号，逻辑主语即主句主语）

特点：位置灵活，常由逗号隔开；表目的用 to do，表伴随/原因/时间看主被动。

口诀：选项中有 to do，可能优先考虑 表目的，但有 逗号隔开且非目的，不一定选它，要看 主被动 + 时间先后！

3. 作表语（位置：系动词之后）

+ doing 含义：令人……的 / 正在进行的（多修饰物）

+ done 含义：感到……的 / 已完成的（多修饰人或状态）

结冰的河水：freezing river（正在结冰）
冷冻食品：frozen food（已冻好）

三、作宾语四大高频考点（口诀 + 辨析全汇总）

  • 考点一：动词 + to do（主动 to do / 被动 to be done）：decide / hope / plan / refuse / afford / promise / pretend / manage / happen / warn
    重点：碰巧做某事 happen to do sth.　｜　警告某人不要做某事 warn sb. not to do sth.
  • 考点二：动词 + doing（主动 doing / 被动 being done）：
    🔥 24 词必背口诀（只跟 doing 作宾语）：
    考虑建议盼原谅，承认推迟没得享：consider, suggest/advise, look forward to, excuse/forgive, admit, delay/put off, enjoy
    避免错过保持练，否定完成停欣赏：avoid, miss, keep, practice, deny, finish, stop, appreciate
    禁止想象才冒险，不禁介意弃逃亡：forbid, imagine, risk, can't help, mind, give up/quit, escape
    特殊：1. suggest / advise / allow sb. + to do（注意：没有 suggest sb. to do！advise / allow sb. to do 成立，suggest 只能用 suggest doing / suggest (that) sb. (should) do）　2. suggest / advise / allow + doing
    b. 词组 + doing & d. have 系列

    • 值得做某事（只有 主动 doing 形式）：be worth doing
    • 想做某事：feel like doing　｜　不想做：don't feel like doing
    • have a good/great/fun time + (in) doing
    • have problem/difficulty/trouble/a hard time + (in) doing

    c. 介词 + doing（重点区分 to 的词性！）

    常规：介词 + doing；to 大部分是不定式 符号 + do，个别是 介词 + doing！
    四个必背 to 作介词短语：
    ① 习惯于：be / get used to doing
    ② 投身/致力于：devote ... to doing
    ③ 反对：object to doing
    ④ 期待：look forward to doing

  • 考点三：动词后 + to do / doing 含义大不同：
    动词+ to do+ doing
    want / need / require（需要）主语是人（主动）：sb. need to do；物作主语被动：to be done主语是物（主动表被动）：doing = to be done（注：doing 和 to be done 不会同时出现！）
    forget / remember忘记/记得要去做（未做）忘记/记得做过（已做）
    stop / go on停下来去做另一件事 / 接着做另一件事停止正在做的事 / 继续做同一件事
    regret遗憾地要做（常接 say/tell/inform）后悔做过某事
    only 结果状语only to do：出乎意料的结果（竟然…）doing：自然而然的结果
    try / managetry to do 尽力去做（不一定成）；manage to do 设法做成try doing 尝试着做一做
  • 考点四：四大“花费”句型：
    take：It takes sb. + 时间 + to do sth. spend：sb. spend + 时间/金钱 + (in) doing / on sth. cost：sth. cost sb. + 金钱 pay：sb. pay + 金钱 + for sth.

四、作定语、独立主格与 7 大高频杂项考点

5. 作定语（位置：名词之后 / 后置定语）

• 将来：主动 to do / 被动 to be done
• 现在正在被动（now）：being done
• 其余时间：主动 doing / 被动 done
• b. 序数词 / 最高级 / the only / the very + 名词 + to do

6. 独立主格（特点：逗号隔开，自带逻辑主语，无连接词）

考点一（天气/时间/政策允许）：Weather / Time / Policy permitting, ...

考点二（工作/作业/任务等着去做）：(With) A lot of work / homework / tasks to do, ...

填谓语黄金总结：要填谓语，连接词 和 主语 缺一不可：
（1）有连接词 + 有主语 → 谓语；（2）有连接词 + 无主语 → 非谓语；（3）无连接词（不管有无主语）→ 非谓语。

对比：独立主格 名词+非谓语，主句；非谓语定语 名词+非谓语+...谓语（整句主语就是该名词）。

7. 七大其他必考考点（专升本高频送分题）：
  1. be done + to do（被动语态还原 to，如 be made to do / be seen to do）
  2. 使役动词“让……做”（三个词：make / let / have）：（1）make/let/have sb. + do（主动省 to）（2）have/make sth. + done（被动让某事被做）（3）have sb. + doing（让某人一直做）
  3. 只能做某事（前有 do 后无 to；前无 do 后有 to）：
    can/could do nothing but + do　｜　have no choice/option but + to do
  4. 宁愿做 A 而不做 B：would rather do than do　｜　prefer to do rather than do
  5. 特殊疑问词（what / how / where / when / which，不含 why）+ to do
  6. 不定代词（something / anything / nothing）后 + to do 修饰（如 something to eat）
  7. 其余高频短语：① 太…以至于不能：too ... to ...　② 迷失在…中：be lost in ...　③ be adj. + to do（无被动，如 easy to understand）；变形 be done + to do；特殊 be worth / busy + doing　④ 一句话，+ doing（自然结果状语）
专项四 · 讲义 P1–P4

定语从句 + 状语从句（Attributive & Adverbial Clauses）

定从“一找二还三连接”秒选关系词，攻克只用 that/which 与介词+which，速背状从 18 组连接词与倍数比较。

一、定语从句三步法与连接词总表

结构：先行词（名词/代词）+ 连接词 + 定语从句　｜　含义：相当于一个形容词，修饰限定前面的先行词。
分类：限定性定语从句（名词和连接词之间 无 逗号）；非限定性定语从句（先行词和连接词之间 有 逗号）。

🎯 定从三步口诀：一找 → 二还 → 三连接
• 一找：1. 找从句前 先行词　2. 找定从位置（找两个谓语：V1…连接词…V2…句末 看连接词后 1 个 谓语；连接词…V1…V2 看连接词后 2 个 谓语，到第二个谓语前结束！）
• 二还：把 先行词 还原到从句中，看作什么 成分（缺主/宾/表/定/状？）
• 三连接：根据“先行词指代 + 所缺成分”确定 关系词。
讲义原句划定从：① He is an old man who is wearing a blue suit.　② The time when I first met my boyfriend was a very difficult period of my life.
先行词代表含义定语从句关系词（含成分要求）
人who（主/宾）、whom（只作宾）、that（主/宾）
物which（主/宾）、that（主/宾）
……的（所属）whose（+ 名词）
一句话（非限定）which（只放句中/后）、as（句首/中/后，译“正如”）
时间（作状语）when（= 介词 + which）
地点（作状语）where（= 介词 + which）
原因（作状语）why（= for which，先行词为 the reason）

关系词可省略情况：1. 先行词在从句中作 宾语 时可省（非限定性及介词后不可省）；2. 从句谓语是被动语态 be done 时本身不需要宾语（切勿误判缺宾语！）。

二、that vs which 核心辨析、as 搭配与特殊先行词

核心考点 2：只用 that 的三大情况
  1. 先行词是不定代词或被不定代词修饰：all, everything, nothing, anything, something, little, much, none, few, the one
  2. 先行词被序数词、最高级、the only / the very（正是、恰恰） 修饰
  3. 先行词既有 人 又有 物 时
🔗 跨专项串联：“序数词 / 最高级” 三连必考点
（1）时态：It is + 序数词/最高级 that + have/has done；It was ... that + had done
（2）非谓语：序数词/最高级 + 名词 + to do
（3）定语从句：连接词只能用 that
核心考点 3：只用 which 与 as（正如，就像）
  1. 非限定性定语从句（有逗号）不用 that（逗号后不 that）
  2. 介词后不用 that：介宾短语 = 介词 + 宾语（人用 whom / 物用 which）
  3. as 五大必背固定搭配：
    （1）众所周知：as is known to all / as we all know
    （2）据我所知：as far as I know / as far as I'm concerned
    （3）正如我们所期待：as we expected
    （4）通常的情况是：as is often the case
    （5）和…一样：the same ... as / such ... as
介词 + which 换算公式

1）时间由小到大：小于一天 at（at 5 p.m.）、等于一天 on（on Sunday）、大于一天 in（in 1999）→ when = at / on / in which

2）地点：小地点 at（at home）、大地点 in（in Shenyang）→ where = in / at / on which

3）原因：为了这个原因 for this reason → why = for which

4）介宾结构：介词 + whom（人）/ which（物）

核心考点 4 & 5：特殊先行词与 whose 转换

（1）The way 作先行词（从句缺方式状语）：首选 in which，次选 that，或 省略。

（2）The case / situation / point / stage / condition 作先行词（表抽象地点）：用 where 引导！

（3）whose + n. 译为“谁的…” = the + n. + of which / of whom = of which / of whom + the + n.

第五次课 · 讲义 P1–P7

名词性从句 + 主谓一致（Noun Clauses & Subject-Verb Agreement）

打通句子成分与三大从句终极辨析，记牢 TAG 是 SB 双宾口诀与主谓一致 11 大必考规则。

一、句子成分总表与名从识别（主/宾/表/同位语）

句子成分含义 / 作用常见充当词性
主语动作的发出者 / 句子的核心主体名词、代词、数词、动名词/不定式、主语从句
谓语说明主语“做什么”或“是什么”动词（实义动词 / 系动词 / 助动词+动词）
宾语动作的承受者（位于及物动词或介词后）名词、代词、非谓语、宾语从句
表语说明主语的身份、性质、状态（位于系动词后）名词、形容词、介词短语、非谓语、表语从句
定语修饰限定名词/代词（“…的”）形容词、名词、介短、非谓语、定语从句
状语修饰动词/形容词/整句（时间/地点/原因/方式等）副词、介词短语、非谓语、状语从句
同位语对前面抽象名词作进一步解释说明（两者等价）名词、同位语从句

名从定义：由一个句子充当名词性成分，4 大类型：主语从句、宾语从句、表语从句、同位语从句。
主从句谓语定位规则：先找 连接词，连接词 后面紧跟出现的是 从句 谓语，剩下的是 主句 谓语！

1. 主语从句识别

（1）位于句首，后接主句谓语动词
（2）It 作形式主语（It is + adj./n./done + that 从句）

2. 宾语从句识别

1. 及物动词 + 从句
2. 介宾结构：介词 + 从句
3. 双宾语：动词 + 人（间宾） + 从句（直宾）
口诀 TAG 是 SB：Tell / Ask / Give / Show / Buy + 人 + 宾从

3. 表语从句识别

位置：位于系动词（be / seem / look / remain 等）之后

考点三：只有 宾语从句 可省 that（单个动宾从句），主语从句 / 表语从句 / 同位语从句 不可省 that！

二、名从 vs 定从全维度对比表 & 考点二～八

从句缺什么 / 代表含义名词性从句连接词定语从句关系词
人who（主/宾）、whom（宾）who / whom / that
物（★最大区别）what（名从无先行词，最常考！）which / that
……的whosewhose
一句话what（所…的事）which / as
时间 / 地点 / 原因when / where / whywhen / where / why
方式howin which / that / 省略（先行词 the way）

  • wh- + ever 规则：除 whether / if / that 外，名从连接词 + ever 表示“无论…… / 凡是……”（如 whoever / whatever / whenever）。当 wh- 与 wh-ever 同时出现，一般优先选 wh-ever（表强烈语气）。
  • 名从成分判断顺序：先看 主语、宾语、表语（核心成分），其次考虑 定语、状语，最后看 句意是否明确（whether/if）或啥也不缺（that）。
  • 考点四（whether vs if）：不作成分，译“是否”，句意 不明确 / 有疑问 时使用（先确认不缺 核心成分 才能选！）。区别：（1）位置：whether 可引导 主从 / 宾从 / 表从 / 同位语从句 / 介宾，if 只能引导 动词后的宾语从句；（2）whether 可与 or / or not 连用，if 不行。
  • 考点五（从句 vs 特殊疑问句）：特殊疑问句用 疑问语序（连接词+助动词+主语）；名词性从句一律用 陈述语序（连接词+主语+谓语）！
  • 考点六（表达原因的表语从句）：……的原因是…… = The reason why ... is that ...（切忌误选 because！）。
  • 考点七（同位语从句 vs 定从）：从句前有抽象名词（如 news / fact / idea / hope / doubt / question），前 4 个确切抽象名词后句意完整直接用 that；doubt / question 看句意，完整用 that，表不确定用 whether。相同点：从句前都有名词；区别：定从 修饰名词，从句缺成分，同位语从句 解释名词内容，从句不缺成分。
  • 考点八（复合从句）：一个句子中含 多个（2 个及以上） 从句，核心是先找到 每个连接词对应的主干与从句边界。
🌳 三大从句终极解题树：
1. 看选项逻辑：表时间/条件/因果/让步逻辑 → 状语从句；代替人/物/成分 → 名从或定从。
2. 看从句前有无名词：① 有名词 → 排查 同位语从句、双宾语（TAG 是 SB）、定语从句；② 无名词 → 排查 主语从句、动/介宾语从句、表语从句。

三、主谓一致 11 大高频考点全集

谓语形式系动词（现在 / 过去）实义动词（现在 / 过去）
主语单数 → 谓语 单数is / am　｜　wasdoes（动词三单）　｜　did
主语复数 → 谓语 复数are　｜　weredo（动词原形）　｜　did

注：实义动词过去式下单复数 同形（都是 did，没有单复数区别）！

  1. 考点一（非谓语作主语）：非谓语（to do / doing）作主语，谓语一律用 单数。
  2. 考点二（并列结构）：A and B → 复数；Both A and B → 复数；The A and the B（两人/物）→ 复数；The A and B（一人兼两职）→ 单数！
  3. 考点三（就近原则 — 离谓语 近 的主语决定）：or / either...or / neither...nor / not only...but also / not...but / there be。
  4. 考点四（就远原则 — 离谓语 远 / 前面 的主语决定）：with / together with / along with / as well as / besides / except / but / including / rather than。
  5. 考点五（金钱/时间/距离/重量）：作主语表 整体 概念 = 单数（如 Ten years is a long time. / 500 dollars is enough. / 10 miles is far.）。
  6. 考点六（each / every / any）：each / every / any / every A and every B（不管几个 every 和 and）都表 单数！
  7. 考点七（7 大易错主谓一致）：
    ① 集合名词：family 表 家庭整体 用 单数，表 家庭成员 用 复数；population 单独作主语表 人口总数 用 单数，前有分数/百分数表 部分人口 用 复数。
    ② people, police 永远表示 复数（特例：a people 表“一个民族”用单数；the police 永远复数）。
    ③ “许多”三组公式：many + 复名 → 复数，many a + 单名 → 单数；more than one + 单名 → 单数，more + 复名 + than one → 复数；a quantity/amount of + 名词 → 单数，quantities/amounts of + 名词 → 复数！（口诀：1、2 组名词 决定单复 看 名词；3 组看 quantity/amount 本身单复！）
    ④ 短语辨析：a number of + 复名（许多）→ 谓语 复数；the number of + 复名（……的数量）→ 谓语 单数。
    ⑤ 分数/百分数/the half / the rest + of + 名词：看 of 后的 名词（可数单数→单数；可数复数→复数；不可数→单数）。
    ⑥ 定从复数：one of + 复名 + 定从 谓语用 复数；the only / very / right one of + 复名 + 定从 谓语用 单数！
    ⑦ 成双物品：shoes / trousers / glasses / scissors 作主语用 复数；前有 a / the pair of 修饰时用 单数（pairs of 用复数）。
  8. 考点八（the + 形容词 / 过去分词）：表示 一类人（复数） — the young / the old / the rich / the poor / the injured 谓语一律用 复数。
  9. 考点九（主语从句作主语）：单个主语从句一般表 单数；特殊：1. 连接词是 what 且 2. 整体是“主系表”结构时，系动词单复数由表语 名词单复数 决定！（如 What we need are good teachers.）
  10. 考点十（学科与专有名词）：以 s 结尾的学科名（physics / maths / politics / economics）及大写专有名词（the United Nations / the United States）都表 单数。
  11. 考点十一（means & news）：means（方法）单复数 同形（mean v. 意味着；means n. 方法）：each/every/either/neither + means → 单数；all/both/these + means → 复数。news（新闻）不可数 → 永远 单数！
